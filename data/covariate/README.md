## Covariate files
- Technical ImmunoSEQ covariates: `immunoSEQ.cov`
- HLA-tcrQTL mapping covariates: `tcrQTL.cov`
** Note: **
  - `tcrQTL.cov` should contain at minimum: sex, age, ancestral PCs, ImmunoSEQ primer set; genotyping centre should be included if PCs were not computed separately for each batch (to avoid collinearity)
